# Память проекта {{PROJECT_NAME}} (Project Memory Hub)

> **Назначение**: Единая точка входа для быстрого сбора контекста перед любой задачей без рекурсивного сканирования всей файловой системы.

---

## Быстрая навигация (Memory Map)

1. 🗺️ **[Архитектурная карта (`codemap.md`)](codemap.md)** — домены/сайты (`SITE_ID`), сервисы `/local/`, инфоблоки, Highload-блоки, шаблоны, компоненты, AJAX-точки и внешние интеграции.
2. 📜 **[Реестр архитектурных решений (`decisions.md`)](decisions.md)** — принятые ADR по стандарту Michael Nygard (*Контекст → Решение → Отклонённые альтернативы → Последствия*).
3. 🚦 **[Статус и «Красные линии» (`status.md`)](status.md)** — активный фокус, история выполненных задач и строгие запреты проекта.
4. 📋 **[Бэклог задач (`../backlog.md`)](../backlog.md)** — приоритетный план развития (Ближайший спринт / В очереди / Техдолг и идеи).
5. 📅 **[Журнал ежедневных изменений (`../daily/`)](../daily/)** — детальные логи в формате `docs/daily/DD.MM.YY.md`.

---

## Регламент обновления (Maintenance Protocol)
После каждой выполненной и проверенной задачи:
1. Обновить `docs/daily/DD.MM.YY.md`.
2. Обновить локальный `README.md` в затронутой директории.
3. Синхронизировать `docs/memory/status.md`, `codemap.md` (при изменении классов/сущностей) и `decisions.md` (при принятии нового ADR).
4. Обновить статус задач в `docs/backlog.md` и подготовить сценарий UAT.
