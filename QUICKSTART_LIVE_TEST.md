# Быстрый старт: запуск и тестирование 4-плагинной экосистемы 1С-Битрикс на живом проекте

> **Главный принцип**: папки плагинов **НЕ нужно копировать** внутрь вашего рабочего Bitrix-проекта!  
> Плагины ставятся **один раз глобально** в `%USERPROFILE%\.gemini\config\plugins\`, а в папку проекта добавляется только лёгкий конфиг `.agents/plugins.json` и каноническая память (`AGENTS.md`, `docs/memory/*`, `docs/backlog.md`).

---

## Шаг 1. Установить или обновить всю экосистему (1 раз на компьютер)

Откройте PowerShell в папке клонированного репозитория `antigravity-bitrix-ecosystem` и выполните (ставится сразу 4 плагина + иконка в левую панель Antigravity IDE):

```powershell
powershell -ExecutionPolicy Bypass -File .\install-ecosystem.ps1
```

*(Если позже вы обновите код плагинов в этой папке — просто выполните эту команду снова: все подключённые проекты сразу получат свежие версии.)*

---

## Шаг 2. Перезагрузить окно Antigravity IDE

1. В окне **Antigravity IDE** нажмите `Ctrl + Shift + P`.
2. Выберите **`Developer: Reload Window`**.
3. Убедитесь, что в **самой левой панели (Activity Bar)** — рядом с Проводником, Поиском и Расширениями — появилась иконка **B (`1C-Bitrix Command Center`)**.

---

## Шаг 3. Открыть живой Bitrix-проект в Antigravity IDE

Откройте папку вашего реального проекта 1С-Битрикс (`File → Open Folder...`), например `D:\Projects\my-bitrix-site`.

*(Если в этом проекте ещё нет Git — рекомендуем сразу выполнить в терминале IDE: `git init` после Шага 4, когда скрипт уже создаст безопасный `.gitignore` под 1С-Битрикс, чтобы в коммит случайно не попали `/bitrix/`, `/upload/` и секреты!)*

---

## Шаг 4. Инициализировать проект (выберите любой из 2 способов)

### Способ А — 1 клик через левую панель IDE (самый удобный)
1. Нажмите на иконку **B (`1C-Bitrix Command Center`)** в левой панели.
2. Нажмите кнопку **«🛠️ Инициализировать проект»**.
3. Выберите профиль плагинов:
   - `store` / `full` — все 4 плагина (`core` + `seo-geo` + `qa` + `marketing`) для интернет-магазина/CRM;
   - `corporate` — `core` + `seo-geo` + `qa` для корпоративного сайта;
   - `minimal` — только `core` (минимум контекста).
4. Скрипт аккуратно создаст `.agents/plugins.json`, `.gitignore`, `AGENTS.md`, `docs/memory/*`, `docs/backlog.md`, `docs/daily/DD.MM.YY.md` (**существующие файлы памяти не перезапишет**), предупредит, если найдёт устаревшие локальные копии плагинов внутри `.agents/plugins/`, и **автоматически скопирует стартовый промпт в буфер обмена**.

### Способ Б — Через терминал PowerShell
```powershell
powershell -ExecutionPolicy Bypass -File .\init-bitrix-project.ps1 -TargetDir "D:\Projects\my-bitrix-site" -Profile store -Name "My Bitrix Site" -UpdateConfig
```
*(Флаг `-UpdateConfig` безопасно обновляет только `.agents/plugins.json`, сохраняя существующую память `docs/memory/*`. Если в папке исходников плагинов версия выше установленной, скрипт сам обновит глобальные плагины автоматически.)*

---

## Шаг 5. Инициализировать Git (если в проекте его ещё нет)

В терминале внутри папки проекта:

```powershell
git init
git status
```
Проверьте в `git status`, что `/bitrix/`, `/upload/` и `.env` игнорируются, после чего сделайте стартовый коммит:
```powershell
git add .gitignore .agents/plugins.json AGENTS.md docs/
git commit -m "chore(antigravity): initialize 1C-Bitrix project memory and plugin profile"
```

---

## Шаг 6. Открыть Command Center Dashboard и проверить интерактивность

1. В левой панели **1C-Bitrix Command Center** нажмите **«🚀 Открыть Дашборд»**.
2. В центре IDE откроется 5-вкладочный дашборд. Проверьте:
   - Переключение всех 5 вкладок (`Оркестратор`, `Знания`, `Бэклог`, `Git и /local/`, `4 Плагина и Бюджет`).
   - Кнопки фильтров треков, сортировку, раскрытие `<details>` с промптом и кнопку **«📋 Скопировать промпт»**.
   - Кнопки в верхней панели дашборда: **«🔄 Обновить скан»** и **«🛡️ QA Preflight»**.

---

## Шаг 7. Провести живое интервью онбординга в чате Antigravity

Откройте чат агента в этом проекте и вставьте скопированный на Шаге 4 промпт (или этот шаблон):

```text
Запусти bitrix-project-init для этого проекта: просканируй /local/, проведи короткое интервью (Greenfield/Brownfield), заполни реальными данными AGENTS.md, docs/memory/{codemap,decisions,status}.md и docs/backlog.md, затем открой Command Center Dashboard v2.1 с живыми моделями и ICE-приоритизацией.
```

Агент:
1. Просканирует реальный код `/local/` (`bitrix-project-scan.mjs`).
2. Задаст 2 компактных раунда уточняющих вопросов (домены, инфоблоки, интеграции, «Красные линии», первые задачи).
3. Заполнит каноническую память и откроет обновлённый Side-Pane Дашборд с точными промптами под ваши модели и квоты.

---

## Как обновлять плагины в будущем

- **Обновить все плагины сразу для всех проектов на компьютере**:
  ```powershell
  git pull
  powershell -ExecutionPolicy Bypass -File .\install-ecosystem.ps1
  ```
- **Поменять профиль плагинов в конкретном проекте (не трогая `docs/memory/*`)**:
  нажмите **«🛠️ Инициализировать проект»** в левой панели IDE и выберите новый профиль (либо запустите `init-bitrix-project.ps1 ... -UpdatePlugins -UpdateConfig`).
