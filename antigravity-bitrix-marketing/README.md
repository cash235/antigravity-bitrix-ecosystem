# 1C-Bitrix Marketing & CRO (`antigravity-bitrix-marketing`)

Universal Conversion Rate Optimization (CRO), Product Lens (ICE anti-busywork), E-commerce & B2B copywriting, retention campaigns, and Visual UX Design Critique plugin for **Google Antigravity** on any **1C-Bitrix** project (corporate, service, B2B catalog, or multisite online store).

Designed as a modular companion to:
- `antigravity-bitrix-core` (Central Orchestrator, D7 architecture, Project Command Center Dashboard v2.0)
- `antigravity-bitrix-seo-geo` (Technical SEO, Schema.org, GEO / AI Search, Analytics)
- `antigravity-bitrix-qa` (Browser Visual QA, Click-Path Audit, Production Readiness)

## What Is Included

### Skills (4)
| Skill | Purpose |
|---|---|
| `bitrix-product-lens` | Product Diagnostic, Founder Review, User Journey Friction Audit, and ICE Prioritization (`Impact × Confidence ÷ Effort`) |
| `bitrix-conversion-copy` | 5-second above-the-fold clarity test, product/category/service copy, trust/warranty/delivery blocks, out-of-stock lead CTAs, Copy Review checklist |
| `bitrix-campaigns-retention` | Campaign brief -> positioning -> landing/email/messenger/ads sequences + Bitrix CRM recovery playbooks (`cart_abandoned`, `search_empty`, repeat buyers) |
| `bitrix-design-critique` | Visual UX & Design Quality Rubric (Visual Hierarchy 0.35, Conversion Clarity 0.30, Mobile Craft 0.25, Consistency 0.10) for Bitrix templates & product cards |

### Subagent (1)
- `bitrix-growth-strategist` — Read-only conversion, product-lens, messaging, and UX strategist that outputs evidence-backed ICE-ranked initiatives compatible with the `antigravity-bitrix-core` Central Orchestrator.

### Always-Active Guardrail (`rules/AGENTS.md`)
Lightweight CRO & marketing discipline (<30 lines, minimal context overhead): evidence-backed claims, 5-second clarity, single-CTA discipline, no fake urgency/reviews, and SEO/D7 safety when modifying templates.

## Installation

### Windows (PowerShell)
```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

### macOS / Linux
```bash
chmod +x ./install.sh && ./install.sh
```

After installation, open **Antigravity -> Customizations** and verify **1C-Bitrix Marketing & CRO** is enabled.
