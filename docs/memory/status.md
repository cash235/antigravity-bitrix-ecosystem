## 3. «Красные линии» (Red Lines — категорически запрещено)
1. Никогда не допускать утечек PII, клиентских доменов, ID счётчиков, локальных абсолютных путей или секретов в отслеживаемые Git-файлы.
2. Никогда не добавлять внешние npm-зависимости в CLI-скрипты или `antigravity-bitrix-ide-panel`.
3. Никогда не нарушать схему `plugin.json` Antigravity (только разрешённые поля, не более 3 `suggestedPrompts`, 0 коллизий скиллов).
4. Никогда не коммитить внутренние служебные файлы `HANDOFF_*.md`.
