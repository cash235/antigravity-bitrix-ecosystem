### ADR-01: Модульная 4-плагинная архитектура и отдельное IDE-расширение
- **Дата**: 2026-11-20 | **Статус**: `accepted` | **Категория**: Core
- **Контекст**: Один монолитный плагин раздувал стартовый Context Budget на проектах, где не нужен маркетинг или SEO, а формат плагинов Antigravity не умеет добавлять иконку в левый Activity Bar IDE.
- **Решение**: Разделить функциональность на 4 независимых плагина (`core`, `seo-geo`, `qa`, `marketing`) + вынести кнопку левой панели в отдельное zero-npm VS Code/Antigravity IDE расширение (`antigravity-bitrix-ide-panel`), переиспользующее скрипты из `core`.
- **Отклонённые альтернативы**: Единый мегаплагин; требование `npm install` / `vsce` для сборки VSIX.
- **Последствия**: Минимальный контекст на проект через `.agents/plugins.json`, простая установка 1 командой `install-ecosystem.ps1`.

### ADR-02: Двухуровневый Live Quota-Aware Model Router
- **Дата**: 2026-11-20 | **Статус**: `accepted` | **Категория**: Orchestrator
- **Контекст**: Хардкод конкретных названий LLM устаревает за месяцы и не учитывает текущие исчерпанные квоты (`0%`).
- **Решение**: Уровень A — динамический опрос `swarm(action="models", all=true)` с автоисключением `0%`-семейств и кросс-провайдерным резервом; Уровень B — переносимые слоты `invoke_subagent` (`flash_lite`/`flash`/`inherit`/`pro`).
- **Отклонённые альтернативы**: Статическая таблица моделей в скиллах.
- **Последствия**: Плагины не устаревают при выходе новых линеек моделей.

### ADR-03: Детерминированный JSON-рендерер дашборда (`artifact` + `webview`)
- **Дата**: 2026-11-20 | **Статус**: `accepted` | **Категория**: UI / Dashboard
- **Контекст**: Ручная генерация ~950 строк HTML+JS моделью приводила к runtime-ошибкам (`ReferenceError` из-за неэкранированных бэктиков в template literals), ломавшим кликабельность всех кнопок.
- **Решение**: Вынести генерацию в `bitrix-dashboard-render.mjs`, передавать данные только через `<script id="dashboard-data" type="application/json">` с экранированием, делегированием кликов, 3-уровневым `copyText()` и строгой нативной стилизацией под Antigravity IDE (`3px` геометрия, без `999px` капсул и «светофора»).
- **Отклонённые альтернативы**: Ручная генерация HTML агентом каждый раз.
- **Последствия**: Гарантированная работоспособность UI и единый код для Side Pane и IDE Webview.

### ADR-04: Cock-up Prevention Gate, 2-шкальный бэклог и матрица разрешений
- **Дата**: 2026-11-24 | **Статус**: `accepted` | **Категория**: Governance
- **Контекст**: При глубоком делегировании субагентам возрастал риск дрейфа от цели, размытых сроков и неконтролируемых действий вне папки проекта.
- **Решение**: Внедрить 3-точечный **Cock-up Prevention Gate** в `rules/AGENTS.md`, оркестратор и все 6 субагентов (с наследованием вглубь), 2-шкальную систему (`Q1–Q4 × S/M/L/XL` + `Est/Actual`), адаптивный расчёт ритма/дедлайнов и визуально редактируемую матрицу границ `.agents/permissions.json`.
- **Отклонённые альтернативы**: Неформальный плоский список задач без DoD и границ доступа.
- **Последствия**: Прозрачная оценка сроков, проверяемое закрытие задач (`100%` чеклист = готово) и предсказуемая безопасность.
